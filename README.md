MUNIS
Military Uniform & Inventory System

Более техническое и международное название. Хорошо подходит для программного продукта.

```
src/
  ui/
    buttons/
      add_btn.rs        - добавляет военного (надо сделать отдельно для вещей, и чего-то ещё)
      export_btn.rs     - экспортируэт в Exel таблицу
      remove_btn.rs     - удаляет ненужные вещи от которых отказался военный
      save_btn.rs       - сохраняет изменения у военног по получению вещей
  main.rs               - главный файл
```
